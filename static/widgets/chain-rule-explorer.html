The chain rule (backprop on a tiny chain)

Values flow forward; the gradient flows backward, multiplying by each step's local slope. The gradient landing on x is the product of all the slopes.

input x
forward → compute values    ← backward multiply the local slopes

Each backward step multiplies by that operation's local slope (how its output changes with its input). Start from 1 at the loss and multiply your way left: the number that reaches x is exactly what loss.backward() stores in x.grad. A real network is this same idea, just with millions of paths.
