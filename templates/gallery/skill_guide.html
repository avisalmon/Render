A skill is a small folder of instructions that teaches an AI coding assistant (Claude Code or GitHub Copilot) to do one job well: build an Excel report, write a commit message, set up a Python project. The assistant reads the skill's description, and when your request matches it, it follows the skill's steps.

What is inside

One file is required, SKILL.md. It starts with a short header between two --- lines, then the instructions in plain words:

---
name: excel-report
description: Builds a monthly Excel report from a CSV file, with totals
  and a chart. Use when the person asks for an Excel report from data.
---
# Excel report

1. Ask which CSV file to use, if it is not clear.
2. Read it with pandas; group by month.
3. Write report.xlsx with openpyxl: one sheet, a total row, a bar chart.
4. Ask before overwriting a file that already exists.
  • name: lowercase English letters, digits and hyphens.
  • description: what it does and when to use it. This is what the assistant reads to decide, so write the words people will say.
  • Next to it you may add a scripts/ folder, examples or reference notes. All of it is text.

Where it lives

  • Claude Code: .claude/skills/excel-report/SKILL.md in your project (or ~/.claude/skills/ for every project).
  • GitHub Copilot: .github/skills/excel-report/SKILL.md in your repository.

The file is the same for both. The gallery's download buttons give you the folder already in the right place.

The easy way: skill-creator

Anthropic publishes a skill that writes skills, skill-creator, in its public repository github.com/anthropics/skills. Copy its folder into .claude/skills/, open Claude Code and say what you want, for example:

Use skill-creator to make a skill that turns my meeting notes
into a short summary with decisions and action items.

It asks a few questions, writes the SKILL.md, and can test it. Read what it wrote, try it on a real task, and fix what needs fixing.

What makes a good skill

  1. One job, said clearly in the description.
  2. Short numbered steps the assistant can follow.
  3. It asks before deleting, overwriting or sending anything.
  4. No passwords, keys or personal data inside it.
  5. Scripts that a person can read: no encoded or hidden parts.

The gallery's automatic check refuses skills that delete or send things they should not, download and run code, or hide what they do. If yours is refused, it tells you what and where, and you can send a fixed version.

Uploading

Send the SKILL.md on its own, or a zip of the whole folder (up to 1MB). Each person can publish two skills, and update each one up to four times.

קובץ אחד הוא חובה, SKILL.md. בראשו כותרת קצרה בין שתי שורות ---, ואחריה ההוראות במילים פשוטות:

---
name: excel-report
description: Builds a monthly Excel report from a CSV file, with totals
  and a chart. Use when the person asks for an Excel report from data.

# Excel report

1. Ask which CSV file to use, if it is not clear.
2. Read it with pandas; group by month.
3. Write report.xlsx with openpyxl: one sheet, a total row, a bar chart.
4. Ask before overwriting a file that already exists.
  • name: אותיות קטנות באנגלית, ספרות ומקפים.
  • description: מה הסקיל עושה ומתי להשתמש בו. לפי זה העוזר מחליט, אז כתבו את המילים שאנשים באמת יגידו. אפשר לכתוב בעברית או באנגלית.
  • לידו אפשר להוסיף תיקיית scripts/, דוגמאות או הערות. הכל טקסט.

  • GitHub Copilot: .github/skills/excel-report/SKILL.md בתוך הריפו.

הקובץ זהה לשניהם. כפתורי ההורדה בגלריה נותנים לכם את התיקייה כבר במקום הנכון.

הדרך הקלה: skill-creator

Anthropic מפרסמת סקיל שכותב סקילים, skill-creator, בריפו הציבורי שלה github.com/anthropics/skills. מעתיקים את התיקייה שלו ל-.claude/skills/, פותחים את Claude Code ואומרים מה רוצים, למשל:

Use skill-creator to make a skill that turns my meeting notes
into a short summary with decisions and action items.

אפשר לבקש גם בעברית. הוא שואל כמה שאלות, כותב את ה-SKILL.md ויכול גם לבדוק אותו. קראו מה הוא כתב, נסו אותו על משימה אמיתית, ותקנו מה שצריך.

מה עושה סקיל טוב

  1. עבודה אחת, שכתובה בבירור בתיאור.
  2. שלבים קצרים וממוספרים שהעוזר יכול לעקוב אחריהם.
  3. הוא שואל לפני שהוא מוחק, דורס או שולח משהו.
  4. אין בתוכו סיסמאות, מפתחות או מידע אישי.
  5. סקריפטים שבן אדם יכול לקרוא: בלי חלקים מוצפנים או מוסתרים.

הבדיקה האוטומטית של הגלריה דוחה סקילים שמוחקים או שולחים דברים שלא צריך, מורידים ומריצים קוד מהאינטרנט, או מסתירים מה הם עושים. אם הסקיל שלכם נדחה, היא אומרת מה ואיפה, ואפשר לשלוח גרסה מתוקנת.

העלאה

שולחים את ה-SKILL.md לבד, או zip של כל התיקייה (עד 1MB). כל אחד יכול לפרסם שני סקילים, ולעדכן כל אחד מהם עד ארבע פעמים.
