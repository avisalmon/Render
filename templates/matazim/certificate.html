{% comment %} The id printed on the paper, so whoever holds it can check it is real years later without needing an account. {% endcomment %} {% comment %} `dir="ltr"` is not decoration. A left-to-right URL dropped into a right-to-left paragraph gets reordered by the bidi algorithm, and the trailing slash jumps to the front: the printed line read "/http://…/verify/054be…" and anybody typing it off the paper would get it wrong. Isolating the direction is the fix; on a page whose whole purpose is to be printed and read back, it is the difference between a working certificate and a dead link. {% endcomment %}
