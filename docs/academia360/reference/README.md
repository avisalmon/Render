# Academia360 reference material

`Academia360/` is a local static site Avi built on another PC in October 2025
to gather and analyse the Academia 360 program (ות״ת). It was never on
GitHub or served anywhere. It is reference only: it shows where the app is
heading, not how to build it. Real app data lives in the database, never in
these files.

It mixes two kinds of material that the app will keep apart (to be decided
with Avi): public material (the program, its guidelines, public facts about
institutions) and committee material (proposals, budgets, reviews, reviewer
assignments, response letters, contacts).

Everything in this folder except this README is git-ignored.
